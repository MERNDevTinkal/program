# Python Learning Projects

A comprehensive collection of Python programs covering fundamental data structures and programming concepts. This repository is designed for learning and practicing core programming skills including linked lists, loops, iterations, and mathematical computations.

## Project Structure

### Files Included

- **linked_List.py** - Linked List Data Structure Implementation
  - `Node` class definition with data and next pointer
  - Traversal and print functionality
  - Length calculation operations
  - Append operations (insert at end)
  - Comprehensive linked list manipulation methods
  - Well-commented implementation for educational purposes

- **program.py** - Programming Exercises and Solutions
  - Loop and iteration patterns
  - Number manipulation and filtering (odd/even)
  - Mathematical computations (sum, multiplication tables)
  - Pattern printing with loops and ranges
  - Solutions from basic to intermediate level problems

## Features

- ✅ Comprehensive linked list operations and implementations
- ✅ Various loop patterns and iteration examples
- ✅ Solutions to common programming problems
- ✅ Well-commented, beginner-friendly code
- ✅ Educational focus with clear explanations
- ✅ Ready-to-run Python scripts

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/MERNDevTinkal/program.git
cd program
```

### Run the Programs

Execute individual Python files:

```bash
# Run linked list examples
python linked_List.py

# Run programming exercises
python program.py
```
