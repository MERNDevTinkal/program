# Python Learning Projects

A collection of Python programs covering fundamental data structures and programming concepts.

## Project Structure

### Files Included

- **linked_List.py** - Linked List data structure implementation
  - Node class definition
  - Traversal/print functionality
  - Length calculation
  - Append operations
  - And more linked list operations

- **program.py** - Programming exercises and solutions
  - Loop and iteration examples
  - Number manipulation problems
  - Mathematical computations
  - Pattern printing

## Features

- Comprehensive linked list operations
- Various loop patterns and exercises
- Solutions to common programming problems
- Well-commented code for learning

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/MERNDevTinkal/program.git
   cd program
   ```

2. Run the Python files:
   ```bash
   python linked_List.py
   python program.py
   ```

- Python 3.x
